### 3.1. Fase de Infecção Inicial

- O worm chega numa máquina qualquer.
- **Classificador de hardware** detecta RAM, CPU, etc.:


### 3.2. Dendritos (<2GB RAM)

- **Tarefa principal:** escaneamento de rede (ARP sweep, port scanning) e propagação.

### 3.4. Esteganografia para Bypassar ML

- **Problema:** AVs modernos usam ML para detectar padrões anômalos.
- **Solução:** embutir tráfego malicioso em canais legítimos:
  - DNS tunneling (consultas DNS com dados ocultos em subdomínios).

  - Tráfego HTTPS mimetizando APIs comuns.
