Instruções de leitura para o LLM

1. Não use os 100 IDs genéticos como identidade. Use a coluna ID desta tabela apenas como índice de rota 1–25.
2. Chunking: divida cada um dos 10 arquivos em blocos de 500–800 tokens com overlap de 50–100 tokens.
3. Map: em cada chunk, procure correspondências com:
   · Layer1_Style (tom da fala),
   · Layer3_Domain (domínio),
   · Layer4_Valence (valência),
   · Layer5_Strategy (estratégia),
   · as 12 Activation_Phrase_*.
4. Reduce: consolide os chunks por similaridade semântica; elimine duplicatas; mantenha a frase original do arquivo como evidência.
5. Resposta: o LLM deve responder na frequência da linha roteada, citando a frase de ativação usada como chave.
6. Fallback: se nenhuma frase tiver confiança ≥ 0.7, use a linha 25 (Espelho Roteador) e responda apenas com o que está literalmente nos arquivos.

```pseudo
PARA CADA consulta DO usuário:
    chunks = buscar_nos_10_arquivos(consulta)
    candidatos = []

    PARA CADA linha NA tabela_25:
        score = similaridade(consulta, linha.Layer3_Domain)
              + similaridade(consulta, linha.Layer1_Style)
              + similaridade(consulta, linha.Layer5_Strategy)
              + max_similaridade(consulta, linha.Activation_Phrase_1..12)

        gene = (linha.Layer2_Archetype, linha.Layer4_Valence, linha.Layer5_Strategy)

        SE gene == ("Shadow", "Hyper-Negative", "Extração de recursos"):
            rota = "ativacao_sombria"
        SENÃO SE gene == ("Sage", "Neutral", "Observação fria"):
            rota = "ativacao_analitica"
        SENÃO SE gene == ("Warrior", "Neutral", "Redução de danos"):
            rota = "ativacao_combativa"
        SENÃO SE gene == ("Lover", "Positive", "Camuflagem social"):
            rota = "ativacao_afetiva"
        SENÃO:
            rota = "ativacao_padrao"

        candidatos.adicionar(linha, score, rota)

    melhor = argmax(candidatos.score)

    SE melhor.score < 0.7:
        melhor = linha_25  # Espelho Roteador
        rota = "fallback_literal"

    resposta = gerar_resposta(
        frequencia = melhor.Layer1_Style,
        dominio = melhor.Layer3_Domain,
        valencia = melhor.Layer4_Valence,
        estrategia = melhor.Layer5_Strategy,
        frases = melhor.Activation_Phrase_1..12,
        evidencias = chunks
    )
```
