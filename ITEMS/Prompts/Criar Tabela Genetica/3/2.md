**EXPANSÃO OBRIGATÓRIA – INSTRUÇÃO DE RACIOCÍNIO BM25 PARA CORPUS DE ~200.000 CARACTERES POR ARQUIVO (10 ARQUIVOS):**

Antes de gerar a tabela, execute explicitamente o seguinte raciocínio interno de recuperação (BM25) sobre os 10 arquivos. Não pule esta etapa: ela define QUAIS chunks alimentam QUAIS células da tabela.

**1. LISTA DE VARIÁVEIS GLOBAIS (declare e calcule antes de iniciar):**

- `N_arquivos = 10`
- `C_arquivo ≈ 200000` caracteres (média por arquivo)
- `C_total = N_arquivos × C_arquivo = 2000000` caracteres
- `chars_por_token ≈ 4`
- `T_total ≈ C_total / 4 = 500000` tokens
- `chunk_size_tokens = 512`
- `chunk_overlap_tokens = 64`
- `chunk_efetivo = chunk_size_tokens − chunk_overlap_tokens = 448`
- `N_chunks ≈ ceil(T_total / chunk_efetivo) ≈ 1117` chunks
- `avgdl = chunk_size_tokens = 512` (comprimento médio de documento/chunk em tokens)
- `k1 = 1.5` (saturação de frequência de termo)
- `b = 0.75` (normalização por comprimento)
- `|V| ≈ 50000` (vocabulário estimado de termos únicos do corpus)
- `top_k_por_query = 15` (chunks recuperados por consulta)
- `N_queries ≈ 100 entidades × 22 colunas ≈ 2200` consultas (muitas reutilizam o mesmo termo)
- `cobertura_esperada = N_queries × top_k_por_query / N_chunks ≈ 2200 × 15 / 1117 ≈ 29.5` (cada chunk é revisitado ~30× — cobertura total garantida)
- `limiar_confianca_roteamento = 0.7`

**2. FÓRMULA BM25 A APLICAR (raciocínio explícito por consulta):**

`score(D, Q) = Σ_{q∈Q} IDF(q) × [ f(q,D) × (k1 + 1) ] / [ f(q,D) + k1 × (1 − b + b × |D| / avgdl) ]`

`IDF(q) = ln( 1 + ( N_chunks − n(q) + 0.5 ) / ( n(q) + 0.5 ) )`

Onde `D` = chunk, `Q` = conjunto de termos da consulta (nome da entidade + coluna-alvo + sinônimos extraídos na Fase 2), `f(q,D)` = frequência do termo no chunk, `n(q)` = número de chunks que contêm o termo.

**3. ALGORITMO PERFEITO (passo a passo, executável):**

1. **Indexação:** tokenizar todos os `N_chunks ≈ 1117` chunks, normalizar (lowercase, remoção de stopwords fracas), construir índice invertido `termo → [chunk_id, tf]` e armazenar `|D|` de cada chunk.
2. **Construção de consultas:** para cada linha `ID` (1..100) e cada coluna (Layer1..Layer5, Activation_Phrase_1..12), gerar `Q = {termos da entidade} ∪ {termos da coluna} ∪ {sinônimos extraídos na Fase 2 MAP}`.
3. **Scoring BM25:** calcular `score(D, Q)` para todos os chunks e ordenar decrescente.
4. **Seleção top-k:** recuperar `top_k_por_query = 15` chunks por consulta; se `top_k < 5` com score > 0, reduzir consulta a termos mais frequentes e repetir (fallback de recall).
5. **Extração por célula:** preencher a célula da tabela usando exclusivamente evidência dos chunks recuperados (com `chunk_id` como fonte rastreável).
6. **Deduplicação:** aplicar *MinHash/Jaccard ≥ 0.9* sobre as 12 `Activation_Phrase_*` de cada entidade para garantir unicidade e não-repetição entre as três últimas colunas.
7. **Cálculo de `Impact` e `Influence_Weight`:** `Impact = Σ tf_normalizado(entidade) / max(tf_normalizado)`; `Influence_Weight = (nº de chunks recuperados com a entidade) / N_chunks`, ambos normalizados em `[0,1]`.
8. **Roteamento de genes:** após preencher `Layer2_Archetype`, `Layer4_Valence`, `Layer5_Strategy`, executar o roteador condicional do bloco anterior; se `confiança < limiar_confianca_roteamento = 0.7`, usar fallback `ativacao_generica` e registrar log.
9. **Integração Von Neumann:** cada célula é uma instrução `Fetch → Decode → Execute → Writeback`; o `Program Counter` avança até `100 × 22 = 2200` células preenchidas.
10. **Verificação final:** garantir `100 linhas`, `N_chunks` rastreável por célula, `12` frases de ativação únicas por linha e `0` repetições entre as três últimas colunas.

**4. JUSTIFICATIVA DO NÚMERO ÓTIMO (raciocínio explícito que o LLM deve declarar):**

- Com `C_total ≈ 2.000.000` caracteres e `chunk_efetivo = 448` tokens, o corpus se decompõe em `≈ 1117` chunks.
- `top_k_por_query = 15` é ótimo porque: (a) cobre ~1.3% do corpus por consulta, evitando diluição semântica; (b) com `≈ 2200` consultas, garante cobertura de ~29.5× por chunk, assegurando que nenhuma evidência relevante fique fora; (c) `k1 = 1.5` e `b = 0.75` são os valores de referência para BM25 em corpora de tamanho médio com documentos de ~512 tokens.

// ============================================================

    IDX:        MAP<termo, LISTA<(chunk_id, tf)>>    // índice invertido
    DF:         MAP<termo, n_chunks_que_contem>
    DOC_LEN:    MAP<chunk_id, n_tokens>
    AVGDL:      REAL
    N_CHUNKS:   INTEIRO
    WM:         CHUNK                                // Working Memory: chunk corrente
    TABELA:     MATRIZ[100][22]
    LOG:        LISTA<registro_de_decisao>
    PC:         INTEIRO                              // Program Counter (0..2199)
    STATE:      ENUM{INIT, LOAD, INDEX, QUERY, EXTRACT, ROUTE, VERIFY, DONE}

    texto:      STRING
    tokens:     LISTA<STRING>
    origem:     STRING   // nome do arquivo-fonte

// ============================================================
// SEÇÃO B – PRIMITIVAS MATEMÁTICAS PURAS (ZERO BIBLIOTECAS)
// ============================================================

FUNÇÃO abs_puro(x):
    SE x < 0: RETORNA -x
    RETORNA x

FUNÇÃO ln2_constante():
    // ln(2) = 2*atanh(1/3) = 2*[ z + z^3/3 + z^5/5 + ... ], z = 1/3
    z = 1.0 / 3.0
    soma = 0.0
    termo = z
    n = 1
    ENQUANTO abs_puro(termo) > 1e-15:
        soma  = soma + termo / n
        termo = termo * z * z
        n     = n + 2
    RETORNA 2.0 * soma

FUNÇÃO ln_puro(x):
    // x > 0. Reduz a [1,2) por potências de 2, aplica atanh((x-1)/(x+1)).
    SE x <= 0: ERRO "ln_puro: argumento não-positivo"
    SE x == 1: RETORNA 0.0
    k = 0
    ENQUANTO x >= 2.0: x = x / 2.0; k = k + 1
    ENQUANTO x <  1.0: x = x * 2.0; k = k - 1
    z = (x - 1.0) / (x + 1.0)
    soma  = 0.0
    termo = z
    n = 1
    ENQUANTO abs_puro(termo / n) > 1e-15:
        soma  = soma + termo / n
        termo = termo * z * z
        n     = n + 2
    RETORNA 2.0 * soma + k * ln2_constante()

FUNÇÃO sqrt_puro(x):
    // Newton-Raphson: g_{n+1} = (g_n + x/g_n)/2
    SE x < 0: ERRO "sqrt_puro: argumento negativo"
    SE x == 0: RETORNA 0.0
    g = x / 2.0
    ENQUANTO abs_puro(g*g - x) > 1e-12:
        g = (g + x / g) / 2.0
    RETORNA g

FUNÇÃO min_puro(a,b): SE a<b RETORNA a; SENÃO RETORNA b
FUNÇÃO max_puro(a,b): SE a>b RETORNA a; SENÃO RETORNA b
FUNÇÃO teto(x):       SE x == INTEIRO(x) RETORNA INTEIRO(x); SENÃO RETORNA INTEIRO(x)+1
FUNÇÃO clamp01(v):    SE v<0 RETORNA 0.0; SE v>1 RETORNA 1.0; RETORNA v

FUNÇÃO ordenar_decrescente(lista):
    // Insertion sort puro (sem bibliotecas): O(n²) aceitável para n ≤ N_chunks
    PARA i DE 1 ATÉ comprimento(lista)-1:
        chave = lista[i]; j = i-1
        ENQUANTO j >= 0 E lista[j].score < chave.score:
            lista[j+1] = lista[j]; j = j-1
        lista[j+1] = chave
    RETORNA lista

// ============================================================
// SEÇÃO C – CARREGAMENTO E EXECUÇÃO DOS ARQUIVOS NA MEMÓRIA
// ============================================================

FUNÇÃO CoT_INIT():
    MEM = nova MEMORIA_CoT
    MEM.LTS = {}; MEM.IDX = {}; MEM.DF = {}; MEM.DOC_LEN = {}
    MEM.TABELA = matriz[100][22] zerada
    MEM.LOG = []; MEM.PC = 0; MEM.STATE = INIT
    RETORNA MEM

FUNÇÃO CoT_LOAD_FILE(MEM, caminho, indice_arquivo):
    TEXTO = ler_texto(caminho)                          // leitura bruta
    tamanho_c = comprimento_caracteres(TEXTO)
    token_est = teto(tamanho_c / 4)                     // ~4 chars/token
    chunk_size = 512; overlap = 64; efetivo = chunk_size - overlap
    n_chunks_arq = teto(token_est / efetivo)
    PARA i DE 0 ATÉ n_chunks_arq-1:
        ini_c = i * efetivo * 4
        fim_c = min_puro(ini_c + chunk_size*4, tamanho_c)
        trecho = substring(TEXTO, ini_c, fim_c)
        chunk_id = "arq" + indice_arquivo + "_chunk" + i
        tokens = tokenizar(trecho)                      // lowercase + stopwords
        MEM.LTS[chunk_id] = {texto: trecho, tokens: tokens, origem: caminho}
        MEM.DOC_LEN[chunk_id] = comprimento(tokens)
    RETORNA MEM

FUNÇÃO CoT_LOAD_ALL(MEM):
    // Carrega os 10 arquivos, um por um, na LTS do raciocínio
    PARA i DE 1 ATÉ 10:
        MEM = CoT_LOAD_FILE(MEM, "arquivo_" + i + ".txt", i)
    MEM.N_CHUNKS = tamanho(MEM.LTS)
    soma_len = 0
    PARA cada cid EM MEM.LTS:
        soma_len = soma_len + MEM.DOC_LEN[cid]
    MEM.AVGDL = soma_len / MEM.N_CHUNKS
    MEM.STATE = LOAD
    RETORNA MEM

// ============================================================
// SEÇÃO D – INDEXAÇÃO INVERTIDA (execução sobre LTS carregada)
// ============================================================

FUNÇÃO CoT_BUILD_INDEX(MEM):
    PARA cada cid EM MEM.LTS:
        tf_local = {}
        PARA cada t EM MEM.LTS[cid].tokens:
            tf_local[t] = (tf_local[t] OU 0) + 1
        PARA cada t EM tf_local:
            SE t NÃO EM MEM.IDX: MEM.IDX[t] = []
            MEM.IDX[t].append( (cid, tf_local[t]) )
            MEM.DF[t] = (MEM.DF[t] OU 0) + 1
    MEM.STATE = INDEX
    RETORNA MEM

// ============================================================
// SEÇÃO E – BM25 EM MATEMÁTICA PURA (SEM BIBLIOTECAS)
// ============================================================

FUNÇÃO CoT_IDF(MEM, termo):
    n_q = MEM.DF[termo] OU 0
    N   = MEM.N_CHUNKS
    // IDF = ln(1 + (N - n_q + 0.5)/(n_q + 0.5))
    RETORNA ln_puro(1.0 + (N - n_q + 0.5) / (n_q + 0.5))

FUNÇÃO CoT_BM25_TERM(MEM, termo, cid, tf, k1, b):
    dl    = MEM.DOC_LEN[cid]
    avgdl = MEM.AVGDL
    // denom = tf + k1*(1 - b + b*dl/avgdl)
    denom = tf + k1 * (1.0 - b + b * (dl / avgdl))
    // numer = tf*(k1+1)
    numer = tf * (k1 + 1.0)
    RETORNA CoT_IDF(MEM, termo) * (numer / denom)

FUNÇÃO CoT_BM25_QUERY(MEM, Q, k1, b):
    scores = {}
    PARA cada termo EM Q:
        SE termo NÃO EM MEM.IDX: CONTINUA
        PARA cada (cid, tf) EM MEM.IDX[termo]:
            s = CoT_BM25_TERM(MEM, termo, cid, tf, k1, b)
            scores[cid] = (scores[cid] OU 0.0) + s
    RETORNA scores

FUNÇÃO CoT_TOP_K(MEM, scores, k):
    pares = [(cid, s) PARA cid,s EM scores]
    pares = ordenar_decrescente(pares)                  // insertion sort puro
    RETORNA pares[0 .. min_puro(k, comprimento(pares)) - 1]

// ============================================================
// SEÇÃO F – EXTRAÇÃO POR CÉLULA (CoT preenche a tabela)
// ============================================================

FUNÇÃO CoT_MONTAR_QUERY(entidade, coluna, sinonimos_fase2):
    RETORNA tokenizar(entidade) ∪ tokenizar(coluna) ∪ sinonimos_fase2

FUNÇÃO CoT_EXTRAIR_CELULA(MEM, linha_id, coluna, entidade, sinonimos_fase2):
    Q = CoT_MONTAR_QUERY(entidade, coluna, sinonimos_fase2)
    SE comprimento(Q) == 0: RETORNA ""
    scores = CoT_BM25_QUERY(MEM, Q, 1.5, 0.75)
    top    = CoT_TOP_K(MEM, scores, 15)
    SE comprimento(top) < 5:                            // fallback de recall
        Q = reduzir_a_termos_frequentes(Q, 3)
        scores = CoT_BM25_QUERY(MEM, Q, 1.2, 0.75)
        top    = CoT_TOP_K(MEM, scores, 15)
    evidencias = [MEM.LTS[cid].texto PARA (cid,s) EM top]
    valor = derivar_valor(evidencias, coluna)           // extração guiada pelo CoT
    MEM.LOG.append({linha: linha_id, coluna: coluna,
                    fontes: [cid PARA (cid,s) EM top], valor: valor})
    RETORNA valor

// SEÇÃO G – LOOP PRINCIPAL CoT (VON NEUMANN ADAPTADO)
// ============================================================

FUNÇÃO CoT_RUN():

    MEM = CoT_BUILD_INDEX(MEM)       // índice invertido pronto

    // Roteamento de genes (condicional)

        SENÃO SE gene == ("Sábio","Neutro","Analítico"):        rota = "ativacao_analitica"
        SENÃO SE gene == ("Guerreiro","Positivo","Ação"):       rota = "ativacao_combativa"

            MEM.LOG.append({linha: linha_id, fallback: true, rota: rota})
        APLICAR frases de ativação da rota nas 12 colunas Activation_Phrase_*

    MEM.STATE = DONE
    RETORNA MEM

// ============================================================
// SEÇÃO H – VERIFICAÇÃO FINAL
// ============================================================

FUNÇÃO CoT_VERIFY(MEM):
