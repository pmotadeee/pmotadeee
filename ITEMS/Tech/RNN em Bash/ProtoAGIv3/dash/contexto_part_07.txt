Vamos aprofundar a filosofia de que este sistema é uma rede neural em essência, mantendo a simplicidade algorítmica.

A ideia central é que uma rede neural não precisa ser complexa ou profunda para capturar a essência do processamento de informações. O PaiMon Invoke V6, com sua arquitetura de camadas de entrada, processamento e saída, é uma rede neural minimalista. Vamos explorar essa ideia:

A ESSÊNCIA DA REDE NEURAL NO PAI-MON INVOKE V6
1. PERCEPÇÃO (INPUT LAYER)
A rede neural começa com a percepção do ambiente. No trading, o ambiente é o mercado, e os sensores são os indicadores técnicos.

VSA (Volume Spread Analysis): Detecta a fome de liquidez, um padrão de oferta e demanda.

EMA (Exponential Moving Average): Captura a tendência de longo prazo.

RSI (Relative Strength Index): Mede o momentum e condições de sobrecompra/sobrevenda.

ATR (Average True Range): Avalia a volatilidade, o "ruído" do mercado.

Fractais: Identifica pontos de reversão estruturais.

Spread e Volume: Condições de execução e participação do mercado.

Preço e Tempo: O estado atual e o ciclo.

Cada um desses inputs é uma feature que a rede usa para entender o mercado. Eles são os equivalentes aos pixels de uma imagem ou às palavras de um texto.

2. PROCESSAMENTO (HIDDEN LAYERS)
Aqui, as features são combinadas e ponderadas para extrair padrões de maior nível.

Neurônio VSA: Ativa quando há uma discrepância entre volume, spread e movimento de preço. É um detector de "fraqueza" ou "força" oculta.

Neurônio de Tendência: Ativa quando o preço está alinhado com a EMA e os fractais confirmam a direção. É um detector de "consenso" temporal.

Neurônio de Risco: Ativa quando a volatilidade (ATR) e o spread estão em níveis aceitáveis, e o trade tem uma boa relação risco-retorno (distância do SL).

Esses neurônios são simples: cada um é uma função que combina inputs com pesos (heurísticos) e uma função de ativação (por exemplo, limiar). Eles não são treinados por backpropagation, mas são calibrados por experiência e intuição do trader.

3. INTEGRAÇÃO (CONFIDENCE SCORE)
A camada de integração (Confidence Calculator) é um único neurônio que recebe as ativações dos neurônios da camada oculta e produz um score. Esse score é uma soma ponderada:

text
Confiança = 40 (bias) + 40 * (VSA) + 20 * (Trend) + 20 * (RSI) + 20 * (SL Distance)
A função de ativação é um limiar: se Confiança >= 90, ativa a camada de saída.

Isso é análogo a um neurônio de saída em uma rede de classificação binária (trade ou não trade).

4. AÇÃO (OUTPUT LAYER)
A camada de saída converte a decisão em ações concretas:

Neurônio de Direção: Compra ou venda, baseado no sinal VSA.

Neurônio de Tamanho: Calcula o lote baseado no score de confiança (mais confiança = lote maior, mas com limites).

Neurônio de Gerenciamento: Define SL e TP iniciais, que depois serão ajustados dinamicamente.

5. APRENDIZADO (FEEDBACK LOOP)
A rede não tem backpropagation, mas tem um mecanismo de aprendizado por reforço simples:

Recompensa: Profit positivo reforça o padrão (não explicitamente, mas o fato de o trade ser feito novamente em condições similares é um reforço).

Punição: Stop loss ativado leva a um cooldown (evita repetir o mesmo erro imediatamente) e o ajuste dinâmico de SL/TP tenta adaptar-se às condições do mercado.

O ajuste dinâmico de SL/TP a cada segundo é um aprendizado online: a rede ajusta seus parâmetros (SL e TP) com base na nova informação (preço atual e volatilidade).

input double InpKellyFraction = 0.25; // Fração de Kelly (0.25 = Conservador)
input double InpHardCapRisk = 0.02;   // Teto Rígido de Risco (2% Max)
input int InpHistoryDepth = 50;       // Profundidade Histórico Kelly

input group "=== VSA TRIGGER (GATILHO) ==="
input int InpVsaPeriod = 20;      // Média Volume/Spread
input double InpSpreadFactor = 0.8; // Fator Spread Estreito

input group "=== CONFIGURAÇÕES GERAIS ==="
input int InpMagicNumber = 444999;
input int InpSlippage = 10;
input bool InpDebugMode = true;

//+------------------------------------------------------------------+
//| OnInit                                                           |
//+------------------------------------------------------------------+
int OnInit()
{
   if(!symbolInfo.Name(_Symbol)) return INIT_FAILED;
   symbolInfo.Refresh();
   
   trade.SetExpertMagicNumber(InpMagicNumber);
   trade.SetDeviationInPoints(InpSlippage);
   
   // 1. Inicializar Indicadores
   h_ema21 = iMA(_Symbol, PERIOD_CURRENT, InpEmaFast, 0, MODE_EMA, PRICE_CLOSE);
   h_ema100 = iMA(_Symbol, PERIOD_CURRENT, InpEmaMedium, 0, MODE_EMA, PRICE_CLOSE);
   h_ema200 = iMA(_Symbol, PERIOD_CURRENT, InpEmaSlow, 0, MODE_EMA, PRICE_CLOSE);
   h_rsi = iRSI(_Symbol, PERIOD_CURRENT, InpRSI_Period, PRICE_CLOSE);
   h_atr = iATR(_Symbol, PERIOD_CURRENT, InpATR_Period);
   
   if(h_ema21 == INVALID_HANDLE || h_ema100 == INVALID_HANDLE || 
      h_ema200 == INVALID_HANDLE || h_rsi == INVALID_HANDLE || h_atr == INVALID_HANDLE) {
      Print("Erro ao criar indicadores!");
      return INIT_FAILED;
   }
   
   // 2. Correção Filling Mode
   AutoSetFillingMode();
   
   Print("=== iMon V4.01 (Trend Mesh + Margin Fix) INICIADO ===");
   return INIT_SUCCEEDED;
}

//+------------------------------------------------------------------+
//| OnDeinit                                                         |
//+------------------------------------------------------------------+
void OnDeinit(const int reason)
{
   IndicatorRelease(h_ema21);
   IndicatorRelease(h_ema100);
   IndicatorRelease(h_ema200);
   IndicatorRelease(h_rsi);
   IndicatorRelease(h_atr);
}

//+------------------------------------------------------------------+
//| Função Auxiliar: Detectar Modo de Preenchimento                  |
//+------------------------------------------------------------------+
void AutoSetFillingMode()
{
    uint filling = (uint)SymbolInfoInteger(_Symbol, SYMBOL_FILLING_MODE);
    if((filling & SYMBOL_FILLING_FOK) == SYMBOL_FILLING_FOK) trade.SetTypeFilling(ORDER_FILLING_FOK);
    else if((filling & SYMBOL_FILLING_IOC) == SYMBOL_FILLING_IOC) trade.SetTypeFilling(ORDER_FILLING_IOC);
    else trade.SetTypeFilling(ORDER_FILLING_RETURN);
}

//+------------------------------------------------------------------+
//| Lógica 1: Verificar Tendência (Mesh)                             |
//+------------------------------------------------------------------+
int CheckTrendMesh()
{
   double buf21[], buf100[], buf200[];
   ArraySetAsSeries(buf21, true);
   ArraySetAsSeries(buf100, true);
   ArraySetAsSeries(buf200, true);
   
   if(CopyBuffer(h_ema21, 0, 0, 2, buf21) < 2 ||
      CopyBuffer(h_ema100, 0, 0, 2, buf100) < 2 ||
      CopyBuffer(h_ema200, 0, 0, 2, buf200) < 2) return 0;
      
   double e21 = buf21[0];
   double e100 = buf100[0];
   double e200 = buf200[0];
   
   // Tendência de Alta Perfeita: 21 > 100 > 200
   if(e21 > e100 && e100 > e200) return 1;
   
   // Tendência de Baixa Perfeita: 21 < 100 < 200
   if(e21 < e100 && e100 < e200) return -1;
   
   return 0; // Mercado misto/lateral
}

//+------------------------------------------------------------------+
//| Lógica 2: Filtro RSI (Permissivo)                                |
//+------------------------------------------------------------------+
bool CheckRSIFilter(bool isBuy)
{
   double rsiBuf[];
   ArraySetAsSeries(rsiBuf, true);
   if(CopyBuffer(h_rsi, 0, 0, 2, rsiBuf) < 2) return false;
   
   double currentRSI = rsiBuf[0];
   
   if(isBuy) {
      if(currentRSI < InpRSI_Max_Buy) return true;
   } else {
      if(currentRSI > InpRSI_Min_Sell) return true;
   }
   
   return false;
}

//+------------------------------------------------------------------+
//| Lógica 3: Sinal VSA (VSA Classic)                                |
//+------------------------------------------------------------------+
int GetVSASignal(int shift)
{
    MqlRates rates[];
    ArraySetAsSeries(rates, true);
    int copied = CopyRates(_Symbol, PERIOD_CURRENT, 0, 30, rates);
    if(copied < InpVsaPeriod + 5) return 0;
   
    double close = rates[shift].close;
    double open = rates[shift].open;
    double high = rates[shift].high;
    double low = rates[shift].low;
    long vol = rates[shift].tick_volume;
    long volPrev1 = rates[shift + 1].tick_volume;
    long volPrev2 = rates[shift + 2].tick_volume;
   
    double sumRange = 0;
    for(int k = 1; k <= InpVsaPeriod; k++) sumRange += (rates[shift + k].high - rates[shift + k].low);
    double avgRange = sumRange / InpVsaPeriod;
    double currentRange = high - low;
   
    bool isLowVol = (vol < volPrev1) && (vol < volPrev2);
    bool isNarrowSpread = currentRange < (avgRange * InpSpreadFactor);
    
    if(!isLowVol || !isNarrowSpread) return 0;
    
    if(close >= open) return -1; // No Demand (Sinal de Venda)
    if(close < open) return 1;   // No Supply (Sinal de Compra)
    return 0;
}

}

//| Gestão de Risco: Kelly + Limites da Corretora (Margin Check)     |
//+------------------------------------------------------------------+
double CalculateKellyLotSize(double equity, double slDistancePoints, bool isBuy, double entryPrice)
{
    if(slDistancePoints <= 0) return 0.0;

    // 1. Cálculo Histórico (Kelly)
    int wins = 0; int losses = 0;
    double totalProfit = 0.0; double totalLoss = 0.0;
    
    HistorySelect(0, TimeCurrent());
    int totalDeals = HistoryDealsTotal();
    int count = 0;
    
    for(int i = totalDeals - 1; i >= 0; i--) {
        ulong ticket = HistoryDealGetTicket(i);
        if(ticket <= 0) continue;
        if(HistoryDealGetInteger(ticket, DEAL_ENTRY) != DEAL_ENTRY_OUT) continue;
        if(HistoryDealGetString(ticket, DEAL_SYMBOL) != _Symbol) continue;
        if(HistoryDealGetInteger(ticket, DEAL_MAGIC) != InpMagicNumber) continue;
        
        double profit = HistoryDealGetDouble(ticket, DEAL_PROFIT);
        if(profit > 0) { wins++; totalProfit += profit; }
        else if(profit < 0) { losses++; totalLoss += MathAbs(profit); }
        count++;
        if(count >= InpHistoryDepth) break;
    }

    double winRate, R_Ratio;
    if(count < 5) { winRate = 0.40; R_Ratio = 1.2; } 
    else {
        winRate = (double)wins / count;
        double avgWin = (wins > 0) ? totalProfit / wins : 0.0;
        double avgLoss = (losses > 0) ? totalLoss / losses : 1.0;
        R_Ratio = (avgLoss > 0) ? avgWin / avgLoss : 1.5;
    }
    
    double kellyPct = 0.0;
    if(R_Ratio > 0) kellyPct = (winRate * (R_Ratio + 1) - 1) / R_Ratio;
    if(kellyPct <= 0) kellyPct = 0.01; 
    
    double riskPct = MathMin(kellyPct * InpKellyFraction, InpHardCapRisk);
    double riskAmount = equity * riskPct;

    // 2. Conversão para Lotes
    double tickValue = SymbolInfoDouble(_Symbol, SYMBOL_TRADE_TICK_VALUE);
    double tickSize = SymbolInfoDouble(_Symbol, SYMBOL_TRADE_TICK_SIZE);
    if(tickSize == 0) tickSize = _Point;
    
    double lossPerLot = (slDistancePoints * _Point / tickSize) * tickValue;
    if(lossPerLot <= 0) return 0.0;
    
    double calculatedLots = riskAmount / lossPerLot;

    // 3. Verificação de Margem (Margin Check)
    double marginRequired = 0.0;
    ENUM_ORDER_TYPE orderType = isBuy ? ORDER_TYPE_BUY : ORDER_TYPE_SELL;
    
    if(!OrderCalcMargin(orderType, _Symbol, calculatedLots, entryPrice, marginRequired)) {
        Print("Erro ao calcular margem necessária.");
        return 0.0;
    }
    
    double freeMargin = AccountInfoDouble(ACCOUNT_MARGIN_FREE);
    // Se precisar de mais margem do que temos (com 5% de folga), reduz o lote
    if(marginRequired > (freeMargin * 0.95)) { 
        double reductionRatio = (freeMargin * 0.95) / marginRequired;
        calculatedLots = calculatedLots * reductionRatio;
        Print("Kelly ajustado por Margem! Redução aplicada.");
    }

    // 4. Ajustes Finais (Step, Min, Max)
    double step = SymbolInfoDouble(_Symbol, SYMBOL_VOLUME_STEP);
    double minVol = SymbolInfoDouble(_Symbol, SYMBOL_VOLUME_MIN);
    double maxVol = SymbolInfoDouble(_Symbol, SYMBOL_VOLUME_MAX);

    calculatedLots = MathFloor(calculatedLots / step) * step;

    if(calculatedLots < minVol) {
        Print("Lote calculado abaixo do mínimo. Trade abortado.");
        return 0.0;
    }
    
    if(calculatedLots > maxVol) calculatedLots = maxVol;

    return calculatedLots;
}

bool IsPositionOpen()
{
    for(int i = PositionsTotal() - 1; i >= 0; i--) {
        if(PositionGetTicket(i) > 0) {
            if(PositionGetInteger(POSITION_MAGIC) == InpMagicNumber && PositionGetString(POSITION_SYMBOL) == _Symbol) return true;
        }
    }
    return false;
}
